# Mohd Khizar Kachi — Portfolio Website

Responsive static portfolio built with HTML, CSS and JavaScript. No build tools, paid hosting, database or API keys are required.

## Publish free with GitHub Pages

1. Sign in to GitHub: https://github.com/zerokhizar-byte (or the account you want to use).
2. Create a **public** repository named `khizar-kachi.github.io` if your GitHub username is `khizar-kachi`. GitHub Pages user sites require the repository name to match the username. If your actual username is different, use `<your-actual-username>.github.io` instead. If you prefer a project site, create a repository such as `khizar-portfolio` and the URL will be `https://<your-username>.github.io/khizar-portfolio/`.
3. Upload the **contents** of this folder (the `index.html`, `styles.css`, `script.js`, `assets` folder and this README) to the root of that repository. Do not upload only the ZIP file.
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to finish. Your site address appears in **Settings → Pages**. It may take a few minutes to become available.
7. Open the public URL on both desktop and mobile and test the resume, certificate files and project report links.

## Update your website

Edit `index.html` for text and links, `styles.css` for design, and `script.js` for interactions. To add a certificate, put its file under `assets/certificates/` and add a matching card in the Certificates section of `index.html`. Keep filenames simple and match letter case exactly.

## Before publishing

- Confirm that the email, LinkedIn and GitHub links are correct.
- The academic section intentionally does not publish detailed marksheets. Replace `CGPA: ADD OFFICIAL VALUE` only with your verified official cumulative CGPA.
- The full Shree Tubes project report is included because you chose to publish it. Confirm that your project team and the company permit public distribution and that the report contains no confidential plant information before enabling public access.
- The certificate gallery displays the certificate files provided. It does not claim that any certificate has been independently verified, and it does not invent verification URLs.
- The website is static. The email link works without a backend; it opens the visitor's email application. No database or paid service is used.
